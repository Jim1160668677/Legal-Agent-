# 09 · UI 原型与组件设计

> 版本：v2.3 | 日期：2026-07-22 | 状态：设计扩展（v2.3 新增 10 组件 + 推理/对比/溯源/律师端页面线框图）
> 影响范围：04 / 06 / 07 / 08 / 11 / 14 / 16 / 17
> 形态：ASCII 线框图 + 组件清单 + 设计 token + 交互规范

---

## 一、设计基调

- **气质**：专业、克制、可信赖。法律场景忌花哨；以信息清晰、可追溯、合规为先。
- **配色**：以"司法蓝"为主色，搭配中性灰；警示用琥珀；成功用青绿；错误用红。
- **字号**：正文 28rpx，标题 32–36rpx，法条引用 26rpx。
- **圆角**：8rpx 卡片，24rpx 按钮。
- **免责**：所有 AI 回答区底部固定 `DisclaimerBanner`，不可隐藏。

## 六、交互规范

1. **法条 chip 行为**：已核实=绿底；未核实=琥珀底+"⚠️ 未核实"；点击展开抽屉显示法条全文 + 来源链接。
2. **免责可见性**：`DisclaimerBanner` 永远贴附在 AI 回答底部，不可滑动隐藏。
3. **引导律师卡片**：仅 `suggestConsultLawyer=true` 时出现，提供"查看附近律师/线上咨询入口"（一期仅外链，无内嵌）。
4. **流式中断**：用户切换页面不中断生成；回到页面继续拼装；超时 30s 自动收尾。
5. **表单分步**：`FormStepper` 支持前进/后退，本地暂存（Storage），断网可继续编辑。
6. **下拉刷新/上拉加载**：列表页统一交互。
7. **隐私首次弹窗**：不可关闭，必须选择"同意并继续"或"退出"。

## 七、无障碍与适老化

- 所有可点击元素最小命中区 88×88 rpx。
- 文字与背景对比度 ≥ 4.5:1（司法蓝 #1E4D8C 对白通过）。
- 提供大字模式入口（`legal:prefs.fontSize`），字号 ×1.25。
- 关键图标带 `aria-label`（小程序 `aria-label` 属性）。
- 表单错误以文字+颜色双通道提示，不仅靠颜色。

## 八、小程序适配注意

- Taro 4.x 跨端：优先微信小程序，H5 降级（按钮尺寸、抽屉动画需双端适配）。
- 长列表用 `ScrollView` 虚拟化，避免节点过多卡顿。
- 图片懒加载，证据缩略图按 200rpx 宽生成。
- 流式输出避免频繁 setState，用 `setData` 节流（每 50ms 合并一次）。
- 云存储 `fileId` 直接用 `<image src>` 渲染。
